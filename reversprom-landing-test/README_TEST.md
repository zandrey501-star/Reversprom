## Тест лендинга «Реверспром»

В архиве:
- `index.html` — страница
- `Pictures/` — изображения (не удаляйте и не переименовывайте папку)

### Как открыть

#### Вариант A (рекомендуется): через локальный сервер
1) Откройте терминал в папке с файлами.
2) Запустите:

```bash
python3 -m http.server 8080
```

3) Откройте в браузере:
- `http://localhost:8080/`

#### Вариант B: двойной клик по `index.html`
Обычно работает, но некоторые браузеры/настройки могут ограничивать внешние запросы.

### Что тестировать
- Форма заявки: имя/контакт/комментарий
- Прикрепление файла в форме (до 10 МБ) и успешная отправка
- Блок «Примеры работ» (открытие модалки “Было/Стало”)
